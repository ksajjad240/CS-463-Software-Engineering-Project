# Dollar Dividend Investment Application

## Overview

The **Dollar Dividend Investment Application** is a web-based platform designed to help users manage and track dividend-paying stock investments. It provides real-time insights into dividend earnings, portfolio performance, and reinvestment strategies.

---

## Technologies Used

- **Java** — Core backend development language
- **Spring Boot** — RESTful API development and dependency management
- **Google Cloud Datastore** — NoSQL database for storing investment and dividend records
- **Google Compute Engine** — Cloud deployment platform
- **React.js** — Interactive and responsive user interface
- **JUnit** — Unit and integration testing framework
- **Git & GitHub** — Version control and portfolio publishing
